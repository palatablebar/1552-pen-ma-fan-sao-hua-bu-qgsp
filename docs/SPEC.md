# 喷码返扫画布数据与算法

导入自备批次或复核估计时阅读。先核对下面的字段和时间窗。查看隔离行原因，再核对估计和派发结果。

## 单据

| 字段 | 用途 | 单位 | 有效区间 |
|---|---|---|---|
| `speed` | 传送带频率 | m/min | 40–235 |
| `head_gap` | 喷头间距 | mm | 2–14 |
| `ink_age` | 墨路启用时长 | h | 1–95 |
| `film_tension` | 膜带牵引 | N | 42–220 |
| `specular` | 反光读数 | % | 3–70 |
| `frames` | 返扫可用帧 | 张 | 4–65 |

`key` 是单号，`cohort` 是作业区，文本先做 NFKC 归一化。`day` 为测量工日，`received` 为到站工日，`revision` 为正整数版次。同版记录出现多个不同测量结果时隔离该单全部版次。缺测可空置，但每条单至少包含四项观测。

`outcome` 与 `result_day` 成对填写。实绩单位为张。 `observed` 省略时为 `true`，只在留架右截尾场景允许 `false`。

### 原始行业单据

允许使用 `form` 对象代替平铺量测。保留单号、版次、工日和标签等顶层字段。表中的换算为 `(单据值 − 原点偏移) / 倍率`。每行内部校验完成后，与平铺数据使用同一分窗、建模和派单过程。

| 单据组 | 原始字段 | 用途 | 倍率 | 原点偏移 |
|---|---|---|---:|---:|
| 喷嘴参数 | `web_cm_per_minute` | 带速厘米每分钟 | 100 | 0 |
| 喷嘴参数 | `nozzle_microns` | 喷距微米 | 1000 | 0 |
| 生产走膜 | `ink_use_minutes` | 墨路启用分钟 | 60 | 0 |
| 生产走膜 | `film_millinewton` | 膜带牵引毫牛 | 1000 | 0 |
| 取像记录 | `reflection_basis_points` | 反光万分数 | 100 | 0 |
| 取像记录 | `camera_snapshots` | 取像帧 | 1 | 0 |

示例见 `sample_data/coder_lot_print_form.json`。混合使用两种量测表示，或单据内读数互相矛盾时，保留隔离原因。

## 时序与训练

拟合 `[1,40)`、校准 `[43,61)`、回放 `[65,84)`、当班从 `88` 日起。前三个窗口的入站和结果都须早于窗口终点。到站日晚于截止日的单据在入站隔离。拟合期冻结补值中位数、均值、尺度及训练包络。

| 特征 | 语义 | 公式 |
|---|---|---|
| `blur_load` | 高速喷头扩散 | `speed*head_gap/100` |
| `ink_dwell` | 墨路驻留 | `ink_age*(1+head_gap/20)` |
| `reflection` | 反光与可见帧 | `specular/(frames+2)` |
| `transport_stretch` | 膜带张力偏离 | `abs(film_tension-115)/60` |
| `unread_buffer` | 读码余量 | `speed/(frames+3)` |

### 残差提升树桩回归

以缺陷数均值开局，逐次寻找能降低残差平方误差的树桩。每次贡献乘学习率，再叠加到估计。

本工作台的独立样本校准方式为可见帧量校正误差。风险校准无法确认正负样本时转人工判读。连续估计使用独立校准残差计算双侧区间，误差尺度随作业条件变化。分布监测对训练和当班量测比较Hellinger 距离。未知作业区、两项缺测或两项明显超训练包络的单据需要人工判读。

## 安排喷码返扫

| 优先级 | 原因码 | 条件 | 处置依据 |
|---:|---|---|---|
| 1 | `CAMERA_SPOT` | `specular >= 56 and frames <= 17` | 更换取像角度后二次返扫 |
| 2 | `HEAD_DISTANCE` | `head_gap >= 11 and speed >= 155` | 喷头间距过大需先复位 |
| 3 | `INK_SETTLE` | `ink_age >= 66 and frames < 25` | 复扫墨路运行末班 |

第一条为暂停规则。其余命中与模型阈值 `12` 共同决定是否列入候选。单据所需工位数按 `1 + int(speed >= 145) + int(frames < 18)` 计算。均衡策略对分区限额，集中复核策略允许把额度集中投入高风险区。未分派原因在导出的处置记录中保留。签发前核对每张当班单和工位余额。

### 返扫帧窗交接

将反光和带速折为预计弃用帧。角度或喷头间距待复位的批次保留取像凭证，清晰帧只有过了停线判读才计入可核数。 在派发环节展开现场安排，或从关联单据回查实际读数。

签发最少补拍量前，以补拍后的总帧数重算冻结特征，并共用当班模型与独立校准得到的上沿。核验量沿用 `min(32, max(12, 2*ceil(upper)))`，清晰帧按 `总帧数 - ceil(总帧数*弃用比例)` 保守计算；从原帧数到量测上限 `65` 逐帧试算，首个清晰帧不少于补拍后核验量的方案才可签发。缺任一项实测、试算超出训练包络或没有校准区间时，该试算不予采用；到上限仍无可用足量方案则转人工。暂停规则、工位额度和成本口径不变，单据详情与帧窗交接记录保留补拍依据和试算轨迹。
